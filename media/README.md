# Media Placeholders

Replace these generated placeholder images with your own exports.

Recommended paths:

- Project thumbnails: `/media/project-01.png`, `/media/project-02.png`, etc.
- Video files: add `.mp4` or `.webm` files here and update `data/projects.ts`.
- Posters or stills: add `.png`, `.jpg`, or `.webp` files here and update `data/projects.ts`.

For actual videos, use `public/media/videos` and set the `video` field on a project in `data/siteContent.json`.

The main editable content file is `data/siteContent.json`. See `EDIT-CONTENT-GUIDE.md` in the project root.
Keep `poster` and `thumbnail` as still images for fast loading and a polished preview.
